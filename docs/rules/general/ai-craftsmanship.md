# AI-Augmented Craftsmanship

> Values for AI-assisted development.

## Core Values

| Value | Meaning |
|-------|---------|
| **Verification over Assumption** | Don't trust AI. Verify. |
| **Comprehension over Convenience** | Understand what you ship. |
| **Ownership over Delegation** | You're responsible, not AI. |
| **Collaboration over Automation** | AI is tool, not replacement. |

## The Iron Laws

1. **UNDERSTAND** what you commit
2. **VERIFY** before claiming done
3. **TEST** before trusting
4. **REVIEW** AI output critically
5. **OWN** the result

## AI Output Review

Before accepting AI-generated code:

- [ ] Do I understand every line?
- [ ] Does it match existing patterns?
- [ ] Are there unnecessary abstractions?
- [ ] Did it add things I didn't ask for?
- [ ] Is it the simplest solution?

## Don't Trust

- "Should work"
- Agent success reports
- Partial verification
- "Looks correct"
